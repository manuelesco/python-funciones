Funciones de Usuario

Bloques de código definidos por el programador

Las funciones de usuario son bloques de código creados por el programador para realizar una tarea específica. Permiten reutilizar código, organizar programas y dividir problemas grandes en partes pequeñas y manejables. En Python, una función se define con la palabra reservada def.

📖 Sintaxis

La estructura básica de un bucle for en Python:

Python sintaxis 
def nombre_funcion(parámetro1, parámetro2, ..., parámetro_n):
    """Docstring: descripción de la función."""
    # cuerpo de la función
    return resultado

donde:

Parte de una funciónDescripciónObligatorio
def palabra reservada que indica la definición de una función. ✅
nombre_función identificador en minúsculas con guiones bajos (snake_case). ✅
() delimitan los parámetros que recibe la función ✅
parámetros variables que reciben los valores que se le pasan a la función ❌
: marcan el inicio del bloque de código de la función ✅
Cuerpo instrucciones que se ejecutarán al llamar a la función ✅
"""Docstring""" texto que describe qué hace la función (opcional pero muy recomendada) ❌
return regresa un valor como resultado de la función ❌

⚠️ Indentación Obligatoria: En Python, el cuerpo de la función DEBE estar indentado con exactamente 4 espacios (o 1 tabulador, pero nunca mezcles ambos). Un error de indentación genera IndentationError y el programa no ejecuta.
💡 Dato importante
Convención de nombres: usa snake_case (se refiere al estilo de escritura en el que cada espacio se reemplaza con un guión bajo) para nombrar tus funciones: calcular_area, obtener_promedio, mostrar_menu. Evita nombres genéricos como f1, funcion, hacer_cosas.
📝 Nota importante
Si una función no tiene return, la función regresa None automáticamente.
None es un objeto especial de Python que representa la ausencia de valor.
Características:
  • Es una palabra reservada de Python (con N mayúscula)
  • Es único: solo existe un None en todo el programa
  • No es lo mismo que 0, "" o False

La definición por sí sola no hace nada; para que su código se ejecute hay que llamarla o invocarla:

📖 Sintaxis

Python sintaxis 
# Sintaxis: si la función NO regresa un valor
nombre_funcion(argumento1, argumento2, ..., argumento_n)

# Sintaxis: si la función regresa un valor
resultado = nombre_funcion(argumento1, argumento2, ..., argumento_n)

donde:

ParteDescripciónObligatorio
nombre_función identificador de la función que se desea invocar o llamar ✅
() delimitan los argumentos que se le pasan a la función ✅
argumentos valores que se envían a la función para que los procese ❌
resultado guarda el valor que regresa la función ❌

Funciones de Usuario sin Parámetros

Funciones que no reciben datos externos

💻 Funciones sin parámetros

Una función sin parámetros es aquella que no recibe ningún dato externo cuando se llama. Se define con paréntesis vacíos ().
Son útiles cuando la función realiza una tarea fija que no depende de datos externos.

📖 Sintaxis

Python sintaxis 
def nombre_funcion():
    """Docstring: descripción de la función."""
    # bloque de instrucciones
    ...

💻 Ejemplo 1:

Python ejemplo 
def saludar():
    """Imprime un saludo genérico."""
    print("¡Hola, bienvenido a Python!")

saludar()   # llamada a la función
salida 
¡Hola, bienvenido a Python!

💻 Ejemplo 2:

Python ejemplo 
def mostrar_menu():
    print("1. Iniciar sesión")
    print("2. Registrarse")
    print("3. Salir")

mostrar_menu()
salida 
1. Iniciar sesión
2. Registrarse
3. Salir

💻 Ejemplo 3:

Python ejemplo 
from datetime import date

def fecha_actual():
    print("Hoy es:", date.today())

fecha_actual()
salida 
Hoy es: 2026-06-27

Funciones con Parámetros

Funciones que reciben datos externos

💻 Funciones con parámetros o Funciones con parámetros posicionales

Una función con parámetros es aquella que recibe datos externos para trabajar con ellos internamente.
Son útiles cuando la función necesita información externa para hacer su trabajo, y esa información puede cambiar cada vez que se llama.

Las funciones con parámetros posicionales son el tipo de función más común en Python. En ellas, los argumentos se asignan a los parámetros según el orden en que aparecen durante la llamada a la función. En otras palabras, la primera posición corresponde al primer parámetro, la segunda al segundo parámetro, y así sucesivamente.

Las funciones con parámetros posicionales son el tipo de función más común en Python. En ellas, los argumentos se asignan a los parámetros según el orden en que aparecen durante la llamada a la función. Es decir, el primer argumento se asigna al primer parámetro, el segundo argumento al segundo parámetro, y así sucesivamente. Por ello, es importante que el orden de los argumentos coincida con el orden de los parámetros definidos en la función.

📖 Sintaxis

Python sintaxis 
def nombre_función(parámetro1, parámetro2, ..., parámetro_n):
    """Docstring: descripción de la función."""
    # bloque de instrucciones que usa parametro1, parametro2, etc.
    ...

nombre_función(argumento1, argumento2, argumento3)
💡 Parámetros vs Argumentos
El parámetro es la variable definida en la función. El argumento es el valor, variable o expresión que se pasa al invocarla.

💻 Ejemplo 1:

Python ejemplo 
def saludar(nombre):
    print(f"¡Hola, {nombre}!")

saludar("Ana")  # ¡Hola, Ana!
saludar("Luis") # ¡Hola, Luis!
salida 
¡Hola, Ana!
¡Hola, Luis!

💻 Ejemplo 2:

Python ejemplo 
def presentar(nombre, edad):
    print(f"Me llamo {nombre} y tengo {edad} años.")

presentar("María", 25)
salida 
Me llamo María y tengo 25 años.

💻 Ejemplo 3:

Python ejemplo 
def mostrar_producto(a, b):
    print(f"El producto de {a} y {b} es {a * b}")

mostrar_producto(4, 5)
salida 
El producto de 4 y 5 es 20
⚠️ El número de argumentos debe coincidir:

Si una función espera tres parámetros, debe llamarse con tres argumentos. 

def promedio(a, b, c):
    return (a + b + c) / 3

print(promedio(8, 9, 10))   # Correcto
print(promedio(8, 9))       # Incorrecto: Produce TypeError
💡 Regla:

El orden en que defines los parámetros posicionales es el orden en que debes pasar los argumentos. Python no lee los nombres, sólo cuenta posiciones; es decir, Python empareja el primer argumento con el primer parámetro, el segundo con el segundo, etc.

⚠️ Precaución:

Si no respetas la regla anterior, la función no produce un error, pero el resultado es diferente porque los valores cambiaron de posición. 

def potencia(base, exponente):
    return base ** exponente

print(potencia(2, 5))   # 32
print(potencia(5, 2))   # 25

Funciones de Usuario con Valor de Retorno

Funciones que regresan un valor

📥 Funciones con valor de retorno

Son funciones que, en lugar de solo imprimir un resultado, usan la palabra clave return para devolver un valor al lugar donde fueron llamadas. Ese valor puede guardarse en una variable, usarse en operaciones o pasarse a otra función.

📖 Sintaxis

Python sintaxis 
def nombre_función(parámetro1, parámetro2, ..., parámetro_n):
    # bloque de instrucciones
    return valor

💻 Ejemplo 1:

Python ejemplo 
import random

def lanzar_dado():
    """Genera un número entero aleatorio entre 1 y 6 y lo regresa."""
    return random.randint(1, 6)

dado = lanzar_dado()   # lanzar_dado() se ejecuta y regresa un número que se asigna en dado
print(dado)            

print(lanzar_dado())   # Otra forma de imprimir lo que regresa lanzar_dado()
salida 
1
3

💻 Ejemplo 2:

Python ejemplo 
def sumar(a, b):
    return a + b

resultado = sumar(3, 4)
print(resultado)  # 7
salida 
7

💻 Ejemplo 3:

Python ejemplo 
def area_rectangulo(base, altura):
    return base * altura

area = area_rectangulo(5, 3)
print(f"El área es: {area} u^2")
salida 
El área es: 15 u^2

💻 Funciones con valor de retorno múltiple

En Python, una función puede devolver más de un valor con una sola instrucción return. Basta con separar los valores con comas; Python los empaqueta automáticamente en una tupla que puedes desempaquetar al recibir el resultado.

📖 Sintaxis

Python sintaxis 
def nombre_funcion(parámetros):
    """Docstring."""
    # cuerpo
    return valor1, valor2, ..., valor_n   # Python empaqueta esto como una tupla

# Desempaquetado al llamar la función
a, b, ..., n = nombre_funcion(argumentos)
💡 ¿Qué ocurre internamente?

return valor1, valor2, ..., valor_n es equivalente a return (valor1, valor2, ..., valor_n). Python crea una tupla con los valores separados por comas y la devuelve como un único objeto. Al asignar el resultado a varias variables con la misma cantidad de elementos (desempaquetado), cada variable recibe el valor en su posición correspondiente.

💻 Ejemplo 1. Menor y Mayor:

Python ejemplo 
def menor_mayor(a, b):
    """Obtiene el menor y mayor de dos números."""
    return min(a, b), max(a, b)

menor, mayor = menor_mayor(8, 3)

print(f"Menor = {menor}")
print(f"Mayor = {mayor}")
salida 
Menor = 3
Mayor = 8

💻 Ejemplo 2. Cociente y residuo de una división:

Python ejemplo 
def dividir(dividendo, divisor):
    """Calcula el cociente y residuo de una división."""
    cociente = dividendo // divisor
    residuo = dividendo % divisor
    return cociente, residuo

cociente, residuo = dividir(27, 4)

print("Cociente:", cociente)
print("Residuo:", residuo)
salida 
Cociente: 6
Residuo: 3

💻 Ejemplo 3. Conversión de segundos:

Python ejemplo 
def convertir_segundos(total_segundos):
    """Convierte una cantidad de segundos en horas, minutos y segundos."""
    horas = total_segundos // 3600
    minutos = (total_segundos % 3600) // 60
    segundos = total_segundos % 60
    return horas, minutos, segundos

h, m, s = convertir_segundos(7384)

print(f"Horas: {h}")
print(f"Minutos: {m}")
print(f"Segundos: {s}")
salida 
Horas: 2
Minutos: 3
Segundos: 4

Ámbito de una Variable

Lugar donde una variable puede ser utilizada

El ámbito (scope) de una variable define en qué partes de tu programa una variable es visible, accesible y modificable. Si intentas usar una variable fuera de su ámbito, Python te devolverá un error de tipo NameError.

Para entender cómo encuentra Python una variable, se utiliza la regla LEGB, que indica el orden exacto en el que busca su nombre:

  1. Local: Variables creadas dentro de una función.
  2. Enclosing: Variables en la función externa (padre) de una función anidada.
  3. Global: Variables definidas en el nivel principal del archivo.
  4. Built-in: Nombres predefinidos de Python (como print(), str).

🏠 1. Ámbito local

Una variable creada dentro de una función tiene ámbito local. Solo puede utilizarse dentro de esa función porque solo existe mientras la función se ejecuta.

💻 Ejemplo:

Python ejemplo 
def saludar():
    mensaje = "Hola"  # variable local
    print(mensaje)

saludar()      # Hola
print(mensaje) # Error: NameError, no existe fuera de la función
salida 
    print(mensaje) # Error: NameError, no existe fuera de la función
          ^^^^^^^
NameError: name 'mensaje' is not defined

🔗 2. Ámbito Enclosing (Anidado o Envolvente)

Ocurre cuando tienes una función dentro de otra. La función interna puede leer las variables de la función externa.

💻 Ejemplo:

Python ejemplo 
def externa():
    nombre = "Ana"

    def interna():
        print(nombre)  # accede a la variable de la función externa

    interna()

externa()  # Ana
salida 
Ana

🌐 3. Ámbito Global

Una variable definida fuera de cualquier función es global: se puede leer desde cualquier parte del archivo.

💻 Ejemplo:

Python ejemplo 
contador = 0  # variable global

def incrementar():
    print(contador)  # se puede LEER sin problema

incrementar()  # 0
salida 
0

🙈 Una variable local puede ocultar a una global:

Python ejemplo 
mensaje = "Hola desde fuera"

def saludar():
    mensaje = "Hola desde dentro"
    print(mensaje)

saludar()
print(mensaje)
salida 
Hola desde dentro
Hola desde fuera

Existen dos variables diferentes, aunque tengan el mismo nombre.
Dentro de saludar() se utiliza la variable local: 

mensaje "Hola desde dentro"

Fuera de la función se utiliza la variable global: 
mensaje = "Hola desde fuera"

La variable local oculta a la variable global dentro de ese ámbito.

💡 Buena práctica general:

En la mayoría de los casos es mejor evitar variables globales dentro de funciones y en su lugar pasar valores como parámetros y retornarlos. Una variable global tiende a hacer el código más difícil de seguir porque el efecto de una función deja de estar contenido en ella misma.


💻 Ejemplo:

Python ejemplo 
# Preferible a usar global
def incrementar(contador):
    return contador + 1

contador = 0
print(contador)
contador = incrementar(contador)
print(contador)
salida 
0
1

🐍 4. Ámbito Built-in (Incorporado)

Contiene los nombres que Python proporciona de manera integrada, por lo que normalmente podemos utilizarlos sin importar ningún módulo, como print, range, etc.

💻 Ejemplo:

Python ejemplo 
print("Hola")

print(len("Python"))

print(max(10, 20, 30))
salida 
Hola
6
30
⚠️ Importante:

Evita nombrar una variable con el mismo nombre que un elemento built-in para no ocultar el elemento built-in en ese ámbito.


💻 Ejemplo:

Python ejemplo 
len = 10
print(len)              # 10
print(len("Python"))    # TypeError
salida 
10
    print(len("Python"))
          ~~~^^^^^^^^^^
TypeError: 'int' object is not callable

Esto funciona, pero ahora len se refiere a nuestra variable y oculta temporalmente la función incorporada len() en ese ámbito.
Por eso es recomendable no utilizar nombres de funciones o tipos incorporados como nombres de variables.

Type Hints

Anotaciones especiales

Los type hints (anotaciones de tipo) te permiten indicar qué tipo de datos espera una función como parámetros y qué tipo devuelve. No son obligatorios (Python sigue siendo dinámico), pero mejoran la legibilidad, ayudan a tu editor a detectar errores, y facilitan el mantenimiento del código.

📖 Sintaxis básica:

  • Usa dos puntos : después del nombre del parámetro para definir su tipo.
  • Usa una flecha -> después de los paréntesis de los parámetros para indicar el tipo que retorna la función.

Python sintaxis 
def nombre_funcion(param1: tipo1, param2: tipo2, ..., param_n: tipo_n) -> tipo_retorno:
    # bloque de código...
⚠️ Precaución:

El type hint no obliga a Python a recibir ese tipo de dato. Es una anotación que sirve principalmente como información para el programador y para herramientas de análisis de código.

💻 Ejemplo: Función sin parámetros y sin valor de retorno.

Python ejemplo 
def menu() -> None
	# bloque de código
	...

-> None indica que la función no devuelve un valor mediante return.

💻 Ejemplo: Función con parámetros y valor de retorno.

Python ejemplo 
def calcular_total(precio: float, cantidad: int) -> float:
	# bloque de código
	...
💡 Idea clave:

Los type hints permiten documentar los tipos de datos que entran y salen de una función, pero Python no los utiliza para impedir automáticamente valores de otros tipos.

🚨 Cosas importantes a tener en cuenta.

1. No se validan en tiempo de ejecución: Python no lanza error si pasas un tipo incorrecto. Los type hints son solo "documentación ejecutable". 

def sumar(a: int, b: int) -> int:
    return a + b

sumar("hola", "mundo")  # No da error

2. Herramientas externas sí los validan: usa mypy o el linter de tu editor (PyCharm, VS Code) para detectar estos errores antes de ejecutar el código.


3. Unión de tipos: se utiliza en los type hints cuando queremos indicar que una variable, parámetro o valor de retorno puede ser de uno de varios tipos. 

def calcular_doble(numero: int | float) -> int | float:
    return numero * 2
	
calcular_doble(10)      # int
calcular_doble(10.5)    # float

La función puede recibir un int o un float y puede regresar un int o un float.

La sintaxis int | str funciona desde Python 3.10+; en versiones anteriores se usa Union[int, str] de typing.
